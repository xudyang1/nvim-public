# Neovim Configuration

## Dependencies

- [git](https://git-scm.com/downloads), `curl`, `wget`, `unzip`, `tar`, `gzip`
- `mason.nvim`: `node`, `npm`, `python`, `cargo`
- `nvim-treesitter`: `gcc` or `clang` with `libstdc++` (linux) and [tree-sitter-cli](https://github.com/tree-sitter/tree-sitter)
- `fzf-lua`: [fzf](https://github.com/junegunn/fzf), [ripgrep](https://github.com/BurntSushi/ripgrep) and [fdfind](https://github.com/sharkdp/fd)
- `LuaSnip`: `make` build `jsregexp`
- `nvim-dap`, `mason.nvim`: `python3-venv` (linux)
- `firenvim`: `firenvim` browser extension
